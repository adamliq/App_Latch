# Support

## Support model

Developer-supported open-source project (community support), maintained on
a best-effort basis. This is not a Splunk-commercial-supported app.

## Getting help

- **Usage questions:** see `USER_GUIDE.md`.
- **Installation/configuration problems:** see `INSTALL.md`, `CONFIGURE.md`,
  and `TROUBLESHOOTING.md` first.
- **Bugs:** open an issue in the project's source repository with:
  - the app version (shown on the About page),
  - your Splunk version/platform (Cloud or Enterprise, shown on the About
    page),
  - the page you were on and what you expected vs. what happened,
  - your browser and version.

## Reporting a security issue

If you believe you've found a security vulnerability, please report it
privately through the project's source repository (e.g. a private security
advisory) rather than as a public issue, so it can be assessed before
public disclosure. Do not include real credentials, tokens, or customer data
in a report — this app does not handle any of those, so a report should
never need to.

## Reporting an accessibility defect

Report accessibility issues the same way as a bug (see above), including
the assistive technology and browser combination you were using, and which
WCAG success criterion you believe is affected if known.
