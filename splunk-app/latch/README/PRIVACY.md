# Privacy and data-handling statement

## Data collected

None. Latch does not collect, transmit, or store any data about its users
or their environment.

## Data transmitted externally

None. The app makes no outbound network requests.

## Data returned to the browser

Only the app's own bundled reference content (taxonomy, source catalogue,
logging patterns, health checks, glossary) and the current Splunk user's
username/theme/version, which Splunk Web already exposes to every app for
display and theming purposes.

## Data stored in Splunk

None. The app creates no indexes, lookups, KV Store collections, or saved
searches, and writes nothing at runtime.

## Browser storage

None used. No cookies, `localStorage`, `sessionStorage`, or `IndexedDB`
entries are created by the app.

## Telemetry

None. This app includes no analytics, usage tracking, or telemetry of any
kind, undisclosed or otherwise.

## Personal information

The only personal information the app displays is the current Splunk
username, shown back to the signed-in user on the Home and About pages. It
is never transmitted anywhere or persisted by the app.

## Data retention

Not applicable — the app stores nothing.
